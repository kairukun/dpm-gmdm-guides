Only authorized editors can change guide content.

Editing isn't available on the published site.

This address is a read-only copy hosted on GitHub Pages, which can only serve files — there is no sign-in service behind it.

To edit guides, run the editor on your computer:

  1. Open the project folder
  2. Run npm start
  3. Go to http://127.0.0.1:8899/login.html

Saving there rebuilds the guide pages, which you can then publish.
