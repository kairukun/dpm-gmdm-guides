Managing Users in FRUM

This guide provides step-by-step instructions for managing users in FRUM. It includes information on adding employees/managers, changing roles, resetting passwords, and transferring employees/managers. If you need to navigate FRUM and perform these tasks, this guide will help you do so efficiently.
