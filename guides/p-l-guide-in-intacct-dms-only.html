P&L Guide in Intacct (DMs Only)

This guide provides step-by-step instructions on how to navigate Intacct and view the Profit and Loss (P&L) statement. It also explains how to review for incorrect charges, access drill-down capabilities, search for invoices, and favorite menu options. Additionally, it provides guidance on fixing authorization issues and viewing invoice images. This guide is essential for individuals using Intacct to effectively manage and analyze financial data.

  5. Tip

  16. 12
    Preview of a P&L
  17. Tip
    All blue text indicates drill down capabilities. The system will let you know when you are at the most detailed level of access when you see a permission denied message.
  18. 13
    Clicking a blue number on the P&L brings up the "General Ledger Report."
  19. Tip
    When reviewing the General ledger report you will notice a column labeled JNL, which is short for “Journal”. - JNL code SE stands for “Standard Entry”. These will be manual entries the accounting team makes. - JNL code PR stands for “Payroll”. While still a manual entry by the accounting team, it signifies data pulled from iSolved. - JNL code BR stands for “Bank Recon”. These are entries from the Banking module, mostly to cash over/short and credit card fees. - JNL code AP stands for “Accounts Payable”. These are from AP, and should have an invoice image attached unless it comes from an EDI feed or was loaded via an Excel file from the vendor. If the column shows AP for accounts payable, then the dollar amount in blue will take you to a copy of the bill.
  20. 14
    Clicking a blue number on the P&L brings up the entry for that debit/credit. This also brings up all entries related to that charge. If there is an invoice attached, it will be a link within the circles shown.
